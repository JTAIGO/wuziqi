# 五子棋

一个微信小程序版五子棋（Gomoku）游戏，纯前端实现，无需云开发。

## 功能

- **双人对战**：本地同屏双人轮流落子
- **人机对战**：AI 执黑先手，支持简单 / 普通 / 困难三档难度
- **规则模式**：
  - 无禁手（经典自由规则）
  - 标准禁手（三三、四四、长连禁手，黑长连判白胜）
- **禁手提示可视化**：黑方回合实时标记棋盘上的禁手点（红叉 + 红圈）
- **悔棋、重开**（重开二次确认）、**计时**、**落子音效**、**终局五连高亮**

## 界面

- 浅色水墨竹林背景，沉浸式自定义导航栏
- 木纹棋盘 + 立体棋子 + 星位标记

## 目录结构

```
├── app.js / app.json / app.wxss   # 小程序入口与全局配置
├── pages/index/                   # 主页面（棋盘、交互、绘制）
├── utils/
│   ├── gomoku.js                  # 五子棋核心规则（胜负判定、禁手）
│   ├── ai.js                      # 人机 AI（棋型评分 + 攻防加权）
│   └── sound.js                   # 音效
└── assets/                        # 背景图等静态资源
```

## 运行

用微信开发者工具导入项目根目录即可预览。

> 说明：`project.config.json` 中的 AppID 为测试号，预览可用；如需上线，请替换为正式小程序 AppID。
